Quick Start

Run the modern GUI with integrated SONAR.

Install dependencies
pip install PyQt5 netifaces
Run from project root
. venv/bin/activate
sudo PYTHONPATH=. python3 python_wrapper/scanner_gui_modern.py

Note: sudo is used because raw packet scanning may require elevated privileges.

Usage Guide

What the application does.

  • Chooses network interface (netifaces)
  • Scans targets/ports (TCP SYN / UDP)
  • Detects OS/service using fingerprints in data/
  • Shows SONAR + network map visualization

Building the raw scanner module (optional)

The project contains a C-extension (core/raw_scan.c) linked with pcap. You may need a C compiler + libpcap installed on your system.

Build example (one of the typical approaches)
python3 setup.py build_ext --inplace

macOS note: setup.py includes Homebrew include/lib hints (/opt/homebrew) for libpcap.

Learn

What W_NETVISUS is and what problems it solves.

Key features

  • Raw packet scanning (TCP SYN / UDP) via C-extension
  • OS and service detection using stored fingerprints
  • Modern PyQt5 GUI with acrylic/dark style
  • 3D-like network map
  • Visual SONAR (waves + glowing host dots)

Use cases

  • Quickly find open ports and exposed services
  • Validate network accessibility and perimeter rules
  • Visualize nearby hosts/activity using SONAR

Entry points

  • network_map_3d.py — map
  • sonar_widget.py — sonar
