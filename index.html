W_NETVISUS • Network Visibility & Port Scanning

Go deep into your
network visibility.

W_NETVISUS is a modern network scanner with a 3D-like network map and a visual SONAR. It supports raw TCP/UDP scanning via a C-extension and uses fingerprints for OS/service detection.

Quick Start

Install dependencies
pip install PyQt5 netifaces
Run from project root
. venv/bin/activate
sudo PYTHONPATH=. python3 python_wrapper/scanner_gui_modern.py
Note: sudo may be required for raw packet scanning (depending on OS and mode).

What you get

  • Raw TCP SYN / UDP scanning via C-extension (core/raw_scan.c)
  • OS/service detection with fingerprints (data/)
  • Modern PyQt5 GUI (python_wrapper/scanner_gui_modern.py)
  • 3D-like network map + SONAR widget
