Learn

What W_NETVISUS does in real networks: discover exposed services, validate reachability, and visualize host activity.

Typical use cases

  • Inventory exposed services on a subnet
  • Check firewall rules (open / filtered / closed)
  • Quick triage: who is alive and what is listening
  • Visual overview via 3D map + SONAR

How it works (high level)

  1. Discover targets (interfaces / IPs)
  2. Scan TCP/UDP (raw C core)
  3. Detect OS/service (fingerprints)
  4. Render results (PyQt5 GUI + SONAR + map)
Architecture stays stable even when UI evolves.

FAQ

Why do I need sudo/admin?
Raw packet operations can require elevated privileges depending on OS policy and scan mode.
Why is a port “filtered”?
A firewall/ACL may drop probes or block replies, so the scanner can’t confirm open/closed reliably.
Is OS detection always accurate?
It depends on fingerprint coverage and network conditions — treat it as best-effort.
