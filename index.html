Quick Start

Install dependencies: 

pip install PyQt5 netifaces

Run from project root: 

. venv/bin/activate
sudo PYTHONPATH=. python3 python_wrapper/scanner_gui_modern.py

Note: sudo may be required for raw packet scanning (depending on OS and mode).

What you get

Fast scan + clear visuals.

  • Raw TCP SYN / UDP scanning via C-extension (core/raw_scan.c)
  • OS & service detection using fingerprints in data/
  • Modern PyQt5 GUI: python_wrapper/scanner_gui_modern.py
  • 3D-like network map (network_map_3d.py) + SONAR widget
